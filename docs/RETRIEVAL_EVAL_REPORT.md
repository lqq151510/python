# DevAssist 片段级检索评估报告

依据合成演示资料原文独立编写标注的片段级检索诊断集；未命中样例用于记录基线局限，不是生产性能评估。

数据集：`devassist-authored-notes-v2`；5 份合成文档，17 个分块，30 个问题。
离线复用应用的解析、分块和 BM25 排序函数；没有连接数据库、读取模型配置或调用模型。

## 指标与判定口径

命中须同时满足文件名正确、片段覆盖标注行号、片段含有标注引用。仅命中文件名不计成功。
标注依据原文独立编写；多条证据按证据条目计算召回，同一个重叠片段的重复命中不重复计数。

| 指标 | 结果 | 分母与定义 |
|---|---|---|
| Top-1 命中率 | 72.7% | 22 个有答案问题，第一条包含至少一条标注证据 |
| Recall@5 | 88.6% | 每个有答案问题前五条召回的证据比例，再对问题取平均 |
| MRR@5 | 0.811 | 第一条正确证据排名的倒数；前五条无正确证据记 0 |
| 无答案返回空结果比例 | 50.0% | 8 个无答案问题中没有返回片段的比例 |
| 无答案返回片段比例 | 50.0% | 无答案问题仍返回片段的比例 |

无答案表示语料没有问题所需的操作证据；返回的片段可能主题相关，但不足以给出该问题的具体答案。这项指标不代表模型已经生成了错误回答。
样例严格通过条件：有答案问题的首条正确且全部证据在前五条；无答案问题返回空结果。

严格通过 20/30；失败样例如实保留。
