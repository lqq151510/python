## 指标与判定口径

命中须同时满足文件名正确、片段覆盖标注行号、片段含有标注引用。仅命中文件名不计成功。
标注依据原文独立编写；多条证据按证据条目计算召回，同一个重叠片段的重复命中不重复计数。

| 指标 | 结果 | 分母与定义 |
|---|---|---|
| Top-1 命中率 | 100.0% | 14 个有答案问题，第一条包含至少一条标注证据 |
| Recall@5 | 100.0% | 每个有答案问题前五条召回的证据比例，再对问题取平均 |
| MRR@5 | 1.000 | 第一条正确证据排名的倒数；前五条无正确证据记 0 |
| 无答案返回空结果比例 | 0.0% | 10 个无答案问题中没有返回片段的比例 |
| 无答案返回片段比例 | 100.0% | 无答案问题仍返回片段的比例 |

无答案表示语料没有问题所需的操作证据；返回的片段可能主题相关，但不足以给出该问题的具体答案。这项指标不代表模型已经生成了错误回答。
样例严格通过条件：有答案问题的首条正确且全部证据在前五条；无答案问题返回空结果。

严格通过 14/24；失败样例如实保留。
