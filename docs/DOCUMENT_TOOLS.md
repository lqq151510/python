# 文档预览与范围检索

验收日期：2026-10-11，Asia/Shanghai。

## 使用方式与范围

知识库列表中的“预览 文件名”读取该文档已保存的片段，按分块顺序展示标题、行号和纯文本。工作台来源面板的“打开来源文档”打开同一个预览，并定位和标记命中片段。关闭预览会清除预览路由参数。

知识库和工作台均提供“检索范围”：全部文档，或当前账号的一份文档。知识库中的“带着这个问题去问答”同时传递问题和范围。只检索原文与生成带来源回答使用相同的范围；关闭知识库选项时，普通问答请求不携带文档 ID。

数据库当前保存的是分块，没有单独保存整篇原始文件。预览如实展示这些分块，长文的重叠内容可能重复；此次没有拼接或宣称可还原完整原始文件，也没有新增数据库迁移或依赖。

## 接口契约

`GET /api/v1/documents/{id}` 返回：

```json
{
  "document": { "id": "UUID", "filename": "guide.md", "chunk_count": 2, "size_bytes": 120, "created_at": "ISO timestamp" },
  "chunks": [{ "id": "UUID", "position": 0, "heading": "标题", "line_start": 1, "line_end": 4, "content": "片段原文" }]
}
```

`position` 从 0 开始，界面片段编号从 1 开始。返回的原文来自已存在的数据库分块，不执行为 HTML。

`POST /api/v1/documents/search` 新增可选字段 `document_id`，响应回传该范围；不指定时仍搜索自己的全部文档。`POST /api/v1/chat` 同样支持该字段，但要求 `use_documents: true`。模型上下文和响应来源均只来自指定文档。

详情、指定范围检索和知识库问答都核对当前用户与文档归属。普通用户及管理员访问他人文档均返回与不存在文档相同的 404、`document_not_found`。UUID 格式错误返回 422；未登录的详情访问返回 401。指定文档无匹配时不会回退到其他文档，知识库问答在模型调用前返回 422、`no_document_evidence`。

预览缓存按账号和文档 ID 分开保存。重新加载期间隐藏旧片段；刷新失败时只显示错误与重试入口。删除当前文档后关闭预览、移除详情缓存、清空旧检索结果，并把选中范围恢复为全部文档。失效来源片段有明确提示。
