# DevAssist 浅色交互原型

采用泽宝选择的第 1 张浅色视觉稿：左侧导航、中央问答、右侧来源原文。

本地预览：<http://127.0.0.1:5174/>。

可以体验提问、加载、示例回答、复制、引用切换、原文查看，以及知识库导入、检索、移除。点击页头“演示示例”可切换正常回答、模型未配置与等待超时。

这是独立的前端原型。问答使用本地示例，导入文档只保留在当前页面内存中，刷新恢复初始数据。检索为简单关键词匹配，不代表后端 BM25；不读取 `.env`、不调用后端或模型、不写应用数据库。

## 本地开发

```bash
npm run dev -- --host 127.0.0.1 --port 5174 --strictPort
npm run build
npm run test:sites
```

源代码位于 `src/`，视觉依据位于 `references/selected-light.png`。实际检查结果与边界见 [design-qa.md](design-qa.md)。截图、临时验收文件和浏览器记录保存在被 Git 忽略的 `.local/evidence/`。

停止此目录的 Vite 进程即可结束预览，不影响主应用或数据库。回滚仅针对该目录内的本轮修改，避免批量重置根项目的已有改动。
